| 2026-09-11 | **Query string TIDAK disimpan di `page_views`, dan `page_views` terkunci penuh dari `authenticated`.** `normalizePath` membuang query string dan fragment sebelum menulis. Tabelnya nol grant, nol policy, dan `rls_checks.sql` §9 meng-assert bahkan klaim Director ditolak di tabelnya — dibaca lewat `adopsi.adopsiReport` yang menegakkan `canViewAdopsi` lebih dulu, ditulis lewat jalur service-role. | Query string memuat isi filter: nama klien, id karyawan, kata kunci pencarian. Menyimpannya berarti membangun **log pencarian per-orang** yang tidak diminta siapa pun, di tabel yang tidak dirancang untuk itu. Dan tabel yang terbuka untuk `authenticated` membuat setiap karyawan bisa membaca jam pemakaian rekannya lewat PostgREST — sistem pengawasan yang persis pemilik katakan ini bukan. Konsekuensi yang dinyatakan: **di rute `GET /adopsi` RLS BUKAN penegaknya**, `canViewAdopsi` lah penegaknya (pola `strategi_share_*`). Ini ditemukan oleh tesnya sendiri: versi pertama rute memakai `readAsActor` dan menjawab **500** karena 42501. | Claude (keputusan teknis) |
