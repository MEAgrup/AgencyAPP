| 2026-08-19 | **🟢 C1 bagian 2 — MESIN LAPORAN KLIEN: domain + API + FE, `clients.total_sales` kini punya penulis tunggal.** Melengkapi bagian 1 (mesin + skema). **`packages/domain/src/report.ts`** meniru pola `riset-awal.ts` `submitBaseline`: browser mem-parse xlsx ke `{filename, aoa, sha256}`; **server** yang `readSheet` → `detectTtam`/`detect` → baca `report_benchmark` versi aktif → `runReport` (jam server, bukan browser) → INSERT `client_reports` + `client_report_berkas`. **Penulisan `clients.total_sales`** = Σ `gmv_runrate_bulanan` dari laporan **TERBARU per platform aktif** klien (bukan hanya laporan yang baru masuk; `distinct on (client_platform_id) order by periode_akhir desc, id desc`), + satu baris `audit_log` (`total_sales_recomputed`, before→after). **Keputusan desain bagian 2:** (a) **rentang fallback** — bila export tak membawa rentang tanggal terbaca, AM boleh mengisi `periode_mulai`/`periode_akhir`; run-rate & `hari_periode` dihitung dari rentang efektif itu, dan `rentang_dari_berkas=false` mencatat bahwa DB memakai tanggal AM, bukan berkas (payload mesin tetap jujur kosong). Tanpa keduanya → tolak `[rentang tanggal tidak terbaca dari berkas — isi periode mulai & akhir]`. (b) **Izin** = tulis: AM pemilik klien + lead Account + Director; baca: + OD (read-everywhere). Read lintas-scope lewat service-role `db()` + gate in-app (pola `getRecapDetail`, hindari O52). (c) **`client_platform_id` ditambahkan ke `PlatformWire`/FE `Platform`** (aditif, shape-parity tetap seimbang) — panel FE butuh id toko sebagai tambatan laporan; ini id natural, bukan field baru. **Rute:** `POST/GET /clients/{id}/reports`, `GET /reports/{id}`, `GET /reports/{id}/html?mode=klien\|internal` (text/html, mode Klien tak me-render blok internal). Wire `clientReport*ToWire` (snake_case, `null` eksplisit) + registrasi shape-parity. **FE `ReportPanel`** di halaman klien: pilih toko → Mingguan/Bulanan → drop `.xlsx` → POST → daftar laporan + tombol unduh HTML Klien/Internal. `route-parity` `KNOWN_GAPS` tetap kosong. **Bukti:** +16 tes `report.domain.test.ts` (izin, run-rate mingguan ≠ GMV mentah, Σ lintas platform, conflict, immutability, render klien≠internal), core 286 · domain 1420 · api 351 hijau, `db-rebuild` 121 tabel + 4 invariant hijau, 3 parity + wire.test hijau. | `clients.total_sales` — komponen GMV Health Score (M13 §6.2 #5) — tak ditulis apa pun di seluruh proyek sejak lahir; ini menutup gap itu.
