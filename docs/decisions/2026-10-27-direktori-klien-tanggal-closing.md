Dihitung server saat baca, tidak disimpan — selalu bisa dihitung ulang dari timestamp. (2) Filter server-side baru di `GET /clients`: `closing_dari` / `closing_sampai` (`YYYY-MM-DD`, tanggal kalender WIB, inklusif kedua ujung; mengaktifkannya otomatis membatasi ke klien hasil closing CDPS), `status_rilis` (`menunggu_finance` = `released_to_account_at IS NULL`, `dirilis` = terisi; kosong = semua), `urut` (`terbaru` default / `terlama` = closing paling lama dulu ⇒ dengan `status_rilis=menunggu_finance` = paling lama menunggu). Nilai tak dikenal / tanggal tak valid ⇒ 400 `[data tidak lengkap, silahkan lengkapi semua pertanyaan wajib!]`. (3) Paginasi keyset tetap pada kolom yang sama (`created_at, id`), `terlama` cukup membalik arah perbandingan; index `idx_clients_created_at` (P1) melayani kedua arah ⇒ **tanpa migrasi / index baru**. (4) RLS & hak akses tidak berubah (kueri tetap lewat `readAsActor`).
