| 2026-07-28 | **O41 sebagian ditutup — route reminder M5 dipindah ke path yang FE & Go pakai, plus test paritas FE↔API sebagai pencegah.** `GET /api/v1/reminders` → **`/api/v1/finance/reminders`** dan `POST /api/v1/reminders/scan` → **`/api/v1/finance/reminders/scan`**. Go **tidak pernah** punya `/api/v1/reminders` (lihat `routes_client_finance.go` baris 32-33), dan `web-internal/src/lib/finance.ts` memanggil varian `/finance/...`, jadi path TS-nya memang deviasi port — halaman **Reminder Pembayaran** 404 di produksi. Perbaikannya **hanya pindah file route + koreksi komentar path**: nol perubahan logika, nol perubahan domain, nol string BI baru, nol migrasi (`finance.reminderDashboard` / `finance.scanReminders` sudah ada dan tidak disentuh). **Pencegah:** `apps/api/src/lib/route-parity.test.ts` — mengekstrak setiap `api.<method>('<path>')` di `web-internal/src/lib/*.ts` (scanner ber-penghitung kedalaman, bukan regex, karena path FE menyisipkan `${cond ? \`?${qs}\` : ''}`) lalu mencocokkannya per segmen ke route yang `apps/api` benar-benar ekspor (`[id]` ≡ `${id}`, query-string yang menempel di segmen terakhir ditoleransi). Sisa 8 gap terdaftar di `KNOWN_GAPS` dengan nama handler Go pendampingnya; test gagal untuk gap BARU dan juga gagal bila entri `KNOWN_GAPS` sudah dilayani, jadi buku besarnya tidak bisa melenceng. Ada guard anti-vacuous (kedua tabel harus terbaca ≥150 route / ≥100 panggilan). **Bukti fail-before/pass-after:** dengan route `/finance/reminders` dihapus sementara, test menyebut persis dua endpoint itu beserta file FE pemanggilnya; setelah dipulihkan, `apps/api` **170 test hijau**. | Kelas cacat yang sama dengan C03-F2 (`quote-preview` 500 di produksi): dua sisi masing-masing punya unit test, nol test melintasi batas HTTP, jadi pasangan yang patah tetap hijau. Memindahkan route saja tidak menutup kelasnya — karena itu pencegahnya digabung ke perbaikan pertama, dan 8 sisanya jadi buku besar yang harus menyusut, bukan catatan lepas di handoff yang bisa hilang. | Orchestrator, sesi 2026-07-28 (temuan O41) |
