Saat dibuka kembali, urutannya WAJIB: ukur selisihnya dulu (Network tab, `/api/v1/me` lewat proxy vs `apps/api` langsung) — 20 ms ⇒ bukan prioritas, 150 ms ⇒ prioritas utama.
